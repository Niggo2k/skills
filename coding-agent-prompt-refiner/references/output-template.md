# Output Template

Use this only as a flexible template; omit sections that do not help the task.

```md
Please [clear statement of intended outcome].

## Goal
[What the user should experience when complete.]

## 1. Audit before implementation
[What the agent must inspect first, if task complexity warrants it.]

## 2. Current problem / context
[What is currently wrong or relevant.]

## 3. Required behavior
[Concrete user-visible behavior.]

## 4. UI / UX requirements
[Hierarchy, layout, states, accessibility, responsive behavior, visual references.]

## 5. Architecture and implementation constraints
[Reuse, dependencies, source of truth, no unnecessary abstractions, security boundaries.]

## 6. Preserve existing behavior
[Contracts and functionality that must remain unchanged.]

## 7. Acceptance criteria
[Testable, observable requirements.]

## 8. Verification
[Commands + manual/visual checks appropriate to the task.]

## 9. Final report
[Changed, reused, decisions, verification results, limitations.]
```
